# BM25开发集冒烟实验分析

更新日期：2026年8月19日

## 实验定位

本实验只验证“已复核证据—问题—相关性标注—检索—评价指标”的链路。语料包含31条已复核证据，问题集包含30题，问题直接从同一批证据构造，因此结果不得作为论文正式对比实验。

## 配置

- 检索方法：BM25 Okapi；
- 分词：英文、数字及G/M代码保留完整词元，中文使用字级一元和二元词元；
- 参数：`k1=1.5`，`b=0.75`；
- 相关性：已复核直接证据记为2级相关；
- 结果文件：`experiments/results/bm25_dev_v0.1_smoke.json`。

## 结果

| 指标 | 数值 |
|---|---:|
| MRR | 0.8833 |
| Recall@1 | 0.7833 |

| nDCG@1 | 0.8000 |
| Recall@3 | 0.9833 |
| Hit@3 | 1.0000 |
| nDCG@3 | 0.9002 |
| Recall@5 | 1.0000 |

## Top-1失误

| 问题 | 首条相关证据排名 | 主要竞争原因 |
|---|---:|---|
| QDEV002 G90锥面R值 | 2 | 圆弧插补证据同样高频出现R、正负和圆心角 |
| QDEV012 G90循环起点 | 3 | 同章节的G90格式与刀轨证据词汇高度重合 |
| QDEV020 G76用途与特点 | 3 | G92、G76证据共同包含螺纹、圆柱、圆锥和循环 |
| QDEV022 G76刀尖角度/切深/余量 | 2 | G76总参数证据覆盖更多查询词 |
| QDEV025 刀补D地址 | 2 | G41/G42/G40定义证据中的“刀具半径补偿”词频更高 |
| QDEV028 G00碰撞风险 | 3 | G70碰撞和G00/G01综合证据与查询共享更多安全词 |

QDEV005需要两条证据回答，Top-1只能覆盖其中一条，因此Recall@1按定义为0.5，但首条命中仍然正确。

## 对后续实验的作用

1. 保留以上问题作为困难开发案例，用于检查向量检索能否区分同一代码内部的语义侧重点。
2. 混合检索应测试BM25与向量分数融合是否改善Top-1，而不只报告Recall@10。
3. 重排器重点比较QDEV002、QDEV012、QDEV020、QDEV025和QDEV028。
4. 正式数据集还需加入无答案、歧义、语音误识别及跨文档问题，不能根据当前30题调出“完美参数”。
