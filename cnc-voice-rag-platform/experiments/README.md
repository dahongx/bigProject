# 实验目录

- `baselines/`：最小可解释基线；
- `configs/`：后续保存固定实验配置；
- `results/`：后续保存逐题结果和汇总，不手工修改；
- `reports/`：后续生成论文表格和错误分析。

`baselines/bm25_baseline.py` 已改为可重复运行的无外部依赖版本，能够读取JSONL语料、问题和证据标注，输出逐题排名及Recall、Hit、MRR、nDCG指标。

当前 `results/bm25_dev_v0.1_smoke.json` 使用31条已复核证据和30道开发题，用于证明实验链路能够运行并保存早期困难案例。由于题目就是从这批证据中编制的，数据规模仍小且没有独立测试集，其数值不能写成论文最终实验结果。具体错误分析见 `reports/bm25_dev_v0.1_smoke_analysis.md`。

正式实验必须冻结更大规模知识库、开发集和独立测试集，并在统一切块、查询与指标配置下比较不同检索方法。
