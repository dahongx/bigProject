# 开发集 v0.1

这是首批 27 页先导语料对应的问题标注入口。目前只建立问题骨架，不把未经人工校正的 OCR 文本写成标准答案。

## 使用顺序

1. `questions.draft.jsonl` 保存问题及类型标注。
2. `reviewed_evidence.v0.1.jsonl` 保存逐页查看原图后校正的证据，并关联原始块编号。
3. `answers.reviewed.jsonl` 保存基于已复核证据形成的答案。
4. `answers.with_citations.jsonl` 是自动生成的展开视图，每条答案直接附带参考文字、页码和来源块。
5. `answers.draft.jsonl` 仅保留最初的空答案骨架，便于追踪标注过程。
6. `retrieval_eval.reviewed.jsonl` 独立保存检索相关性标注，不从问题页码提示参与检索。
7. `validation_report.json` 检查问题、答案、证据、检索标注及来源块之间的引用完整性。

## 当前边界

- 这些问题用于流程联调和检索开发，不作为最终论文测试集。
- `source_page_hint` 仅帮助标注者定位，不可作为检索输入。
- 正式评测时问题集与知识库版本必须冻结，并记录 SHA256。
- 同一问题的答案证据必须来自已复核块，不能仅依据常识填写。

当前30题已经完整走通并完成原图复核，共关联31条已复核证据。题型包括事实查询14题、条件查询8题、对比查询4题和步骤查询4题；其中简单9题、中等16题、困难5题，多段证据题6题。

当前数据主要来自编程教材选页，因此编程知识占比高。下一步扩展时应优先补充无答案、歧义、语音误识别、跨文档和安全类问题。正式测试集必须另建且保持盲测，避免调参污染。
