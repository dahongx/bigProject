## 二、完整构造流程

### 阶段1：原始文档准备
```
输入：FANUC数控编程手册_杜军_化工出版社.pdf (339页)
位置：data/raw/

说明：
- 这是唯一的原始输入
- 不可修改，作为最终依据
- 当前只处理了其中27页（选页）
```

### 阶段2：OCR处理
```bash
脚本：scripts/build_ocr_blocks.py
输入：data/raw/*.pdf + 页面选择列表
输出：
  - data/parsed/DOC004/pages/*.json（原始OCR）
  - data/parsed/DOC004/rendered/*.png（页面图片）
  - data/parsed/DOC004/blocks.batch_001.draft.jsonl（617个来源块）

过程：
1. 使用PaddleOCR识别PDF页面
2. 恢复章节标题层级
3. 分离正文、代码、表格
4. 分配稳定的block_id（格式：DOC004_P111_B001）
5. 保留原始页码、印刷页码、章节路径
```

**关键文件**：`data/parsed/DOC004/blocks.batch_001.draft.jsonl`
- 共617个来源块
- 每个块有：block_id, page, title_path, text, type

### 阶段3：人工复核队列生成
```bash
脚本：scripts/build_data_review_queue.py
输入：blocks.batch_001.draft.jsonl + reviewed_evidence.v0.1.jsonl
输出：data/parsed/DOC004/data_review_queue_v0.2.csv

作用：
- 标记P0高优先级问题（42项）
- 问题类型：表格、低置信度OCR、代码格式
- 提供原图路径供人工核对
```

**当前状态**：等待协作者填写42个P0项的修订

### 阶段4：生成切块矩阵
```bash
脚本：scripts/build_chunk_matrix.py
输入：blocks.batch_001.draft.jsonl
输出：data/chunks/DOC004/v0.2-draft/*.jsonl（4套配置）

策略：
1. fixed_t256_o51    - 固定256 token，51重叠
2. fixed_t512_o102   - 固定512 token，102重叠
3. fixed_t1024_o205  - 固定1024 token，205重叠
4. structural_t512   - 结构化，最大512 token

每个chunk保存：
- chunk_id（唯一标识）
- text（完整文本）
- retrieval_text（检索用文本）
- source_block_ids（来源块列表）
- source_fragments（精确字符范围）
- pdf_pages, printed_pages（页码）
- title_paths（章节路径）
- citation（引用格式）
```

### 阶段5：Gold候选映射
```bash
脚本：scripts/map_gold_chunk_matrix.py
输入：
  - chunks/*.jsonl（4套切块）
  - reviewed_evidence.v0.1.jsonl（31条证据）
输出：chunk_matrix_v0.2/gold_candidates.*.jsonl

过程：
1. 读取每条证据的source_block_ids
2. 对每套切块，找到包含这些block_id的chunk
3. 通过source_fragments精确匹配字符范围
4. 避免"只碰到block一小部分"的误判
```

### 阶段6：完整性校验
```bash
脚本：scripts/validate_chunk_matrix.py
输入：整个chunk_matrix_v0.2/目录
输出：validation_report.json

检查项：
- chunk数量正确
- 没有重复chunk_id
- 没有空chunk
- token计数有效
- 所有问题都有gold候选
- 文件哈希一致
```

**当前状态**：4套配置全部通过校验 ✓

## 七、关键概念

### Block（来源块）
- 最小的内容单元
- 有稳定的block_id
- 不会变化（除非人工修订）
- 是所有切块的来源

### Chunk（切块）
- 检索的基本单元
- 由一个或多个block组成
- 保存source_block_ids链接
- 不同策略生成不同chunk

### Evidence（证据）
- 人工标注的答案证据
- 绑定到source_block_ids
- 不绑定到chunk_id（因为切块会变）

### Gold Candidate（gold候选）
- 每道题的相关chunk列表
- 通过source_block_ids自动映射
- 每套切块有自己的gold映射
