# PaddleOCR环境安装问题排查与解决

更新日期：2026年8月13日

## 问题诊断

当前遇到的问题：
1. ✅ pip配置文件损坏（已修复，已备份为pip.ini.bak）
2. ⚠️ 系统设置了SOCKS代理：`all_proxy=socks5h://127.0.0.1:7890`
3. ⚠️ pip缺少pysocks支持库，无法使用SOCKS代理
4. ⚠️ SSL证书验证问题

## 解决方案（请手动执行）

### 方案1：临时关闭代理后安装（推荐）

**步骤**：

1. **临时关闭系统代理**：
   - 如果你用的是Clash/V2Ray等代理工具，暂时退出或关闭
   - 或者在系统设置中临时禁用代理

2. **打开PowerShell并执行**：
```powershell
cd E:\big\cnc-voice-rag-platform
.\.venv-ocr\Scripts\Activate.ps1

# 清除代理环境变量
$env:all_proxy = ""
$env:ALL_PROXY = ""
$env:http_proxy = ""
$env:https_proxy = ""
$env:HTTP_PROXY = ""
$env:HTTPS_PROXY = ""

# 安装PaddlePaddle
python -m pip install paddlepaddle -i https://pypi.tuna.tsinghua.edu.cn/simple

# 安装PaddleOCR和其他依赖
pip install paddleocr pypdfium2 pillow pyyaml tqdm rank-bm25 jieba

# 验证安装
python -c "import paddle; print('PaddlePaddle:', paddle.__version__)"
python -c "import paddleocr; print('PaddleOCR:', paddleocr.__version__)"
```

3. **安装完成后可以重新开启代理**

### 方案2：配置pip使用代理（如果必须保持代理开启）

```powershell
cd E:\big\cnc-voice-rag-platform
.\.venv-ocr\Scripts\Activate.ps1

# 先安装pysocks支持
# 下载whl文件手动安装，或者：
curl https://pypi.org/simple/pysocks/ -o pysocks.html

# 然后正常安装
pip install pysocks
pip install paddlepaddle -i https://pypi.tuna.tsinghua.edu.cn/simple
pip install paddleocr pypdfium2 pillow pyyaml tqdm rank-bm25 jieba
```

### 方案3：下载whl文件手动安装

如果网络问题无法解决：

1. **访问清华镜像站**：
   - PaddlePaddle: https://pypi.tuna.tsinghua.edu.cn/simple/paddlepaddle/
   - 选择适合Python 3.9 Windows的whl文件下载

2. **手动安装**：
```powershell
cd E:\big\cnc-voice-rag-platform
.\.venv-ocr\Scripts\Activate.ps1
pip install 下载的文件路径.whl
```

### 方案4：使用Anaconda环境（备选）

如果pip一直有问题，可以用conda：

```powershell
conda create -n cnc-ocr python=3.9
conda activate cnc-ocr
pip install paddlepaddle paddleocr pypdfium2 pillow pyyaml tqdm rank-bm25 jieba
```

## 遇到问题？

把错误信息告诉我，我会帮你分析！

常见问题：
- ❌ "SSL certificate verify failed" → 临时关闭代理
- ❌ "Cannot connect to proxy" → 清除代理环境变量
- ❌ "No matching distribution" → 检查Python版本和镜像源
- ❌ "DLL load failed" → 可能需要安装VC++ Redistributable
