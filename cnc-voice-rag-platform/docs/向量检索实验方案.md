# 向量检索基线实验方案

更新日期：2026年8月19日

## 一、实验目标

在P0来源块校正完成后，建立中文向量检索基线，与BM25在相同评测集上对比。

## 二、技术选型

### 向量模型
- **首选**：BAAI/bge-m3
  - 理由：与当前分词器一致，支持8192 token输入
  - 已有tokenizer，只需下载模型权重
  - 位置：`E:\big\cnc-voice-rag-platform\models\bge-m3`

### 向量库
- **首选**：FAISS (faiss-cpu)
  - 理由：轻量、本地、快速
  - 无需额外服务
  - 适合小规模实验（<1000 chunks）

## 三、实验配置

### 基线配置
```yaml
model: BAAI/bge-m3
max_length: 512  # 与切块token上限一致
normalize: true  # L2归一化
metric: cosine   # 余弦相似度
top_k: 10
```

### 对比切块
与BM25使用相同的4套切块：
1. fixed_t256_o51
2. fixed_t512_o102
3. fixed_t1024_o205
4. structural_t512

### 评测集
- 使用相同的30道问题
- 使用相同的gold mapping
- 计算Hit@1, Hit@5, Hit@10, MRR

## 四、实验流程

### 步骤1：下载BGE-M3模型
```python
from sentence_transformers import SentenceTransformer

model = SentenceTransformer(
    'BAAI/bge-m3',
    cache_folder='E:/big/cnc-voice-rag-platform/models',
    device='cpu'  # 或 'cuda' 如果有GPU
)
```

### 步骤2：构建向量索引
```python
import faiss
import numpy as np

# 对每套切块构建索引
for profile in ['fixed_t256_o51', 'fixed_t512_o102', ...]:
    # 加载chunks
    chunks = load_chunks(profile)
    
    # 批量编码
    texts = [c['content'] for c in chunks]
    embeddings = model.encode(texts, normalize_embeddings=True)
    
    # 构建FAISS索引
    dimension = embeddings.shape[1]
    index = faiss.IndexFlatIP(dimension)  # 内积=余弦（已归一化）
    index.add(embeddings.astype('float32'))
    
    # 保存索引
    faiss.write_index(index, f'data/indexes/{profile}_bge-m3.index')
```

### 步骤3：检索评测
```python
# 加载问题
questions = load_questions()

# 对每个问题检索
for q in questions:
    query_embedding = model.encode([q['question']], normalize_embeddings=True)
    scores, indices = index.search(query_embedding, k=10)
    
    # 评估相关性（与BM25相同的逻辑）
    evaluate_retrieval(indices, gold_mapping[q['id']])
```

## 六、注意事项

1. **使用相同评测集** - 确保公平对比
2. **记录检索时间** - 向量检索通常更慢
3. **先导实验** - 结果标记为draft，不直接进入论文
4. **小语料偏差** - 27页数据可能不足以体现向量优势
