# 新增硕士论文全文对标分析

更新日期：2026年8月11日

## 一、复核结论

本次新增的6篇文件均为可提取文本的完整硕士学位论文。全文复核后，现有课题路线无需推倒重来，但应明确区分两类图：

- 系统数据流图：说明ESP32、ASR、RAG、LLM和TTS怎样连接；
- 论文研究技术路线图：说明研究问题、方法设计、对比实验、消融实验和系统验证的先后关系。

本课题仍采用“结构与元数据感知RAG + CNC语音查询规范化 + ESP32验证平台”，不加入知识图谱。语音是第二个可实验的方法点和落地入口，不承担从零训练ASR模型的任务。

## 三、由全文反推的实验主线

### 3.1 文本RAG实验

1. 固定长度分块 + BM25；
2. 固定长度分块 + 向量检索；
3. BM25 + 向量检索融合；
4. 标题层级/语义边界分块；
5. 增加型号、系统和版本元数据约束；
6. 增加重排；
7. 增加证据充分性、冲突判断和拒答。

指标至少包括Recall@K、MRR、nDCG、证据命中率、答案忠实性、可回答/不可回答判定和响应时延。每个增强项均保留消融结果，不能只展示最终系统。

### 3.2 语音查询实验

1. 干净文本查询作为上限；
2. 通用ASR原始文本作为基线；
3. 术语/代码表规则规范化；
4. 检索候选辅助的受约束规范化；
5. 低置信度关键代码请求确认。

除CER/WER外，应单列术语准确率、代码准确率、查询恢复率及规范化前后的Recall@K和答案正确率。这样能够证明语音方法对下游RAG的实际增益，而不只是证明转写文字更像参考文本。

### 3.3 系统验证实验

依次测试文本接口、服务器麦克风、噪声回放和ESP32实机。记录ASR、规范化、检索、生成、TTS各阶段时延，并统计端到端任务完成率、打断/继续/重复等语音交互功能。硬件实验是落地验证，不替代前两组方法实验。

## 四、推荐论文方法章节结构

- 第3章：数控领域知识库与分层评测集构建；
- 第4章：面向数控文档的结构与元数据感知检索增强方法；
- 第5章：面向CNC术语和代码的语音查询规范化方法；
- 第6章：语音交互式知识服务系统实现与工业场景验证。

这种写法吸收了朱鹏丞论文的“语音方法—RAG系统—实验”结构、张书睿论文的“结构化索引—消融”结构和孙文利论文的“工业系统—任务测试”结构，同时避免把知识图谱、ASR训练、NL2SQL和硬件开发同时变成主任务。
