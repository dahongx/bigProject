## 一、数控手册获取渠道

### 🎯 首选：FANUC系统

**推荐理由**：市场占有率高、公开资料多、术语规范、容易验证

**重点收集型号**：
- FANUC 0i-MF（加工中心常用）
- FANUC 0i-TD（车床常用）
- FANUC 0i-D（通用型）

**获取途径**：

1. **官方渠道**：
   - FANUC官网：https://www.fanuc.com
   - FANUC中国：https://www.fanuc.cn/zh-cn/service/manual
   - 注册账号后可下载部分公开手册

2. **淘宝/闲鱼**：
   - 搜索"FANUC 0i 手册 PDF"
   - 通常5-20元可购买电子版
   - 注意核对版本和完整性

3. **学术资源**：
   - 高校图书馆电子资源
   - 职业院校数控实训中心
   - 机械工程学院资料室

4. **开源社区**：
   - GitHub搜索"CNC manual"
   - 工业论坛（如CNCzone、数控论坛）
   - 不要下载盗版或破解版，注意版权

5. **企业渠道**：
   - 联系数控机床制造企业
   - 联系FANUC代理商
   - 说明是学术研究用途

### 备选：西门子840D

**获取途径**：
- 西门子工业支持中心
- Siemens官网技术文档库
- 相对FANUC更难获取免费版本

### 备选：华中数控HNC-8系列

**获取途径**：
- 华中数控官网：http://www.hncnc.com
- 国产系统，可能更容易获得企业支持
- 联系华中数控市场部或技术支持

## 二、必须收集的手册类型（优先级排序）

### ⭐⭐⭐⭐⭐ 必须有（至少1-2份）

1. **编程手册**：
   - 包含G/M代码完整说明
   - 编程示例和参数说明
   - 这是论文最核心的数据源

2. **参数说明书**：
   - 系统参数定义
   - 参数设置方法
   - 用于参数查询实验

### ⭐⭐⭐⭐ 优先收集（至少1份）

3. **报警手册**：
   - 报警代码含义
   - 原因分析和处理方法
   - 用于故障查询实验

4. **操作手册**：
   - 机床操作步骤
   - 面板功能说明
   - 用于操作知识查询

### ⭐⭐⭐ 建议收集

5. **维护手册**：
   - 日常保养
   - 润滑说明
   - 定期维护项目

6. **连接手册**：
   - 接口说明
   - 通讯设置
   - 可选

## 三、手册质量检查清单

收集到PDF后，立即检查：

- [ ] 文件能否正常打开
- [ ] 文字是否可以复制（非扫描件优先）
- [ ] 如果是扫描件，图像是否清晰
- [ ] 目录是否完整
- [ ] 页码是否连续
- [ ] 文件大小是否合理（过小可能不完整）
- [ ] 版本和发行日期是否明确
- [ ] 语言是中文还是英文（中文优先）

**检查方法**：
```python
python cnc-voice-rag-platform/scripts/parse_documents.py your_manual.pdf
```

## 四、文档登记规范

每收集到一份手册，立即登记到：
`cnc-voice-rag-platform/data/manifests/document_registry.csv`

**必填字段**：
- 文档ID（DOC001, DOC002...）
- 文件名（保持原文件名）
- 厂商、数控系统、型号
- 文档类型（操作/编程/参数/报警/维护）
- 版本和发布日期
- 页数和文件大小
- 来源（官网/淘宝/学校/企业）
- 许可情况（公开/限内部/商业）

**可选但建议填写**：
- 文件SHA256哈希（用于版本追踪）
- 备注（文档特点、质量评价）

## 八、测试问题制作

已提供5个示例问题模板，继续扩充到20-30题：

### 问题来源

1. **从手册目录生成**：
   - 每个章节标题可以变成一个问题
   - 例如："4.2 G01直线插补" → "G01指令是什么意思？"

2. **从手册FAQ生成**：
   - 很多手册有常见问题章节
   - 直接改写成测试问题

3. **从实际使用场景构想**：
   - 想象工人在现场会问什么
   - "机床报警SV0401怎么处理？"
   - "如何设置Z轴零点偏移？"

4. **从论坛和问答社区收集**：
   - 数控论坛的提问
   - 百度知道、知乎的数控问题
   - 改写成规范表达

### 问题类型分配（建议）

最初20-30题建议分配：
- 事实查询（代码含义）：8题
- 步骤查询（操作方法）：5题
- 参数查询：3题
- 报警查询：3题
- 对比查询：3题
- 综合查询：3题
- 无答案查询：2题

### 标准答案来源

1. **直接从手册抄录**：
   - 找到相关段落
   - 用自己的话改写（避免版权问题）
   - 记录页码和章节

2. **综合多处信息**：
   - 一个问题的答案可能分散在多处
   - 整合后形成完整答案

3. **无答案问题**：
   - 故意设计手册中不存在的问题
   - 用于测试拒答能力
   - 例如："如何用数控机床炒菜？"

## 十、常见问题

### Q1：找不到免费的FANUC手册怎么办？
**A**：
1. 先用淘宝购买（通常10-20元）
2. 联系学校图书馆馆际互借
3. 改用华中数控等国产系统（更容易获得支持）
4. 最坏情况：用数控教材+国标暂时替代

### Q2：手册是扫描版，文字无法复制怎么办？
**A**：
1. 使用OCR工具（PaddleOCR、ABBYY）
2. 如果图像清晰，OCR准确率可达95%+
3. 少量手册可以考虑手工输入关键部分
4. 优先寻找文字版PDF

### Q3：收集到的手册有版权限制怎么办？
**A**：
1. 学术研究属于合理使用范围
2. 论文中不直接复制大段原文
3. 数据集不公开发布
4. 引用时注明来源
5. 如有疑问，咨询导师或法务

### Q4：需要收集多少份手册才够用？
**A**：
- **最少**：2-3份（能做基础实验）
- **合适**：3-5份（能做完整实验）
- **理想**：5-8份（能做版本对比实验）
- **不建议**：10份以上（数据管理复杂）

### Q5：英文手册可以用吗？
**A**：
可以，但需要注意：
1. 中文ASR实验需要中文问题
2. 可以人工翻译关键部分
3. 或者用翻译API处理
4. 英文手册更适合做跨语言实验（加分项）
