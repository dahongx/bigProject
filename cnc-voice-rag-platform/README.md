# 数控加工现场语音RAG知识服务验证平台

本目录是论文实验与硬件验证平台的底座。总体原则是把语音终端与论文核心算法解耦：

- `vendor/xiaozhi-server/`：从 `xinnan-tech/xiaozhi-esp32-server` 抽取的语音网关，负责ESP32通信、VAD、ASR、LLM调用和TTS回传。
- `services/cnc-rag/`：后续实现论文自己的数控领域RAG服务，负责文档解析、索引、检索、重排、证据组织和回答生成。
- `docs/`：架构、裁剪边界、论文大纲和实验设计。

## 为什么不直接修改完整小智项目

完整上游还包含管理后台、移动端、数字人、声纹、视觉、MCP、IoT控制、音乐和多种第三方模型适配器。论文验证平台只需要：

1. ESP32与服务端的WebSocket音频通信；
2. Silero VAD；
3. 一个ASR实现；
4. CNC-RAG服务；
5. 一个TTS实现；
6. 终端上的按键、麦克风、扬声器和可选屏幕。

第一阶段保留上游后端原貌，确保协议链路可运行；待硬件和模型选定并跑通后，再删除未使用的provider。过早删除动态加载模块容易造成隐蔽的导入错误。

## 推荐运行链路

```text
ESP32麦克风
  -> WebSocket/Opus
  -> Silero VAD
  -> ASR
  -> CNC术语、代码与参数查询纠错
  -> CNC-RAG服务
  -> 结构化、安全约束回答
  -> TTS
  -> WebSocket/Opus
  -> ESP32扬声器/屏幕
```
