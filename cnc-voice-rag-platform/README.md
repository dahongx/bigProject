# 数控加工现场语音RAG知识服务研究项目

这是论文、实验代码和硬件验证平台的主目录。后续与本课题直接相关的新文件原则上都放在这里，不再散落到 `E:\big` 根目录。

## 当前研究定位

- 暂定题目：面向数控加工现场的语音交互式检索增强知识服务研究；
- 方法主体：CNC语音查询规范化、领域文档检索、证据约束生成和分层评价；
- 验证平台：ESP32语音终端；
- 不做：知识图谱、机床控制、传统传感器故障诊断和通用大模型训练。

具体模型和算法不提前锁死。BM25、向量检索、RRF、重排器以及旧FAQ项目的方法目前都是候选基线或参考；后续如果新方法在同一数据集、同一指标下更好，可以替换。
